# Recetas del mundo

Trabajo Práctico Final (Opción B) - Módulo 3: Desarrollo con React.js - UTN.

Aplicación hecha con React y Vite que usa la API pública [TheMealDB](https://www.themealdb.com/api.php) para mostrar recetas en cards.

## Qué hace

- Muestra las recetas de la API en cards (imagen, nombre, categoría, origen y una descripción corta).
- Tiene un buscador para buscar recetas por nombre (en inglés, por ejemplo "chicken").

## Cómo ejecutar el proyecto

1. Instalar Node.js si no lo tenés.
2. Clonar el repositorio y entrar a la carpeta.
3. Instalar las dependencias:

```
npm install
```

4. Iniciar el proyecto:

```
npm run dev
```

5. Abrir en el navegador la dirección que aparece en la terminal (por ejemplo http://localhost:5173).
